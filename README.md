# 🧼 Sistema de Gestión de Lavandería - UAB

Este proyecto es un sistema web desarrollado con **Flask**, **Tailwind CSS** y **MySQL** que permite gestionar de forma eficiente el servicio de lavandería para los estudiantes internos de la **Universidad Adventista de Bolivia**.

---

## 🚀 Tecnologías utilizadas

- 🐍 Python + Flask
- 🎨 Tailwind CSS
- 🗃️ MySQL
- 🔐 JWT para autenticación
- 🌐 HTML + CSS + JS

---

## ⚙️ Requisitos previos

- Python 3.10+
- Node.js y npm (para Tailwind CSS)
- MySQL (para base de datos)

---
